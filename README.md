# 과제 타이머

마감이 다가올수록 게임 체력(HP) 게이지가 줄어드는 대학생용 과제 관리 웹앱 초안입니다.

## 주요 기능

- 과제 등록·수정: 유형(보고서·PPT·문제풀이·기타), 마감일시, 분량을 넣으면 예상 소요 시간 자동 계산
- HP 게이지 대시보드: 마감 빠른 순 정렬, 24시간 안 깜빡임, 6시간 안 흔들림
- 지금 시작해야 할 과제: 시작 마지노선(마감 − 소요 시간)이 3시간 안이거나 지난 과제 표시
- 자료·작성 가이드: PDF·docx·pptx·xlsx·hwpx·txt를 읽어 핵심어와 요구사항을 뽑고, 쟁점별 분석·분량 배분·제출 전 체크리스트 제공
- 아카이브: 생존율, CLEAR! 목록, GAME OVER 과제 처리, 삭제 후 8초 되돌리기

## 실행

빌드 없이 `index.html` 하나로 동작합니다. 브라우저로 파일을 열거나 정적 호스팅(GitHub Pages 등)에 올리면 됩니다.

- 데이터는 브라우저 localStorage에만 저장됩니다.
- PDF 읽기는 cdnjs의 pdf.js 3.11.174를 필요할 때 불러옵니다.
- AI 분석은 Claude 아티팩트 안에서 열었을 때만 동작하고, 그 밖에서는 규칙 기반 자동 분석으로 대신합니다.
